METHOD — how this list was built
  • Source: all bonded tokens on pump.tires (PulseChain launchpad) — ~950 candidates.
  • Paid filter: token has a paid DexScreener profile — checked via DS /orders/v1 (approval date shown in the PAID column); enforced by refresh.py.
  • Mcap filter: sub-55550000 PLS MCap (≈ $698 today) to get in — FDV = total supply × price, priced on-chain from the PulseX WPLS pair. A row that climbs stays in FULL LIST; it moves to SAVED at ≥ 555,500,000 PLS (≈ $6,983 today). Only crossing a line moves a coin: up through 555,500,000 → SAVED, down through 55,550,000 → FULL LIST; nothing moves in between. Price alone never sends a row to FELL OFF.
  • LP filter: ≤ 1 token-token LP per the PulseX subgraph (V1 + V2), dust pairs ignored (excludes wide LP networks).
  • FELL OFF is the error bucket: no paid profile, more than 1 token-token LP, or a manual move — never price.
  • Vibes filter: subjective "good meme" pass — manual, not scored.
  • Auto-check: 🚀 button re-verifies every row via DexScreener (batched), moves fallers into FELL OFF and resurrects recovered ones back to FULL LIST. Tokens in SAVED / PICKS get fresh data but never move.
  • Discovery: python3 refresh.py locally — refreshes the bonded pool, verifies all tokens, and pulls in any new bonded tokens that meet criteria. Add --commit to push.
  • Source of truth: master.json (gitignored) — every token ever seen; sections only move, tokens never get deleted.
